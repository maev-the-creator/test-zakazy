# ORDER FORGE — история версий

Пометка **[сервер]** — нужно обновить Code.gs у кондитерской: вставить новый `apps-script/Code.gs` в Apps Script →
«Начать развертывание» → «Управление развертываниями» → ✏️ → Версия: «Новая версия». Не «Новое развертывание»!

## 1.2.0 — 3 ноября 2026
- Свой дизайн у каждого клиента: файл клиента `css/theme.css` (подключается последним на всех страницах,
  обновления его не трогают). В `css/styles.css` — роли для темы: шапка и первый экран, поля, бейджи, панель.
  В `client.json` — `theme` (файл темы, цвет вкладки, цвета иконки). Пример — тема «Ваниль» (`clients/example.theme.css`).
  У существующих клиентов после `upgrade` добавьте `css/theme.css` (можно пустой) — `check-client` подскажет.

## 1.1.0 — 3 ноября 2026
- Эталон для клиентов: файлы продукта (`product-files.txt`) и клиента, `client.json` → `npm run apply-client`,
  `npm run new-client`, `npm run check-client`, `npm run upgrade`.
- **[сервер]** Code.gs одинаковый у всех: обязательные свойства `SITE_URL`, `GITHUB_REPO`, новое `BAKERY_NAME`.
  Версия сервера (`SERVER_VERSION = 2`) и баннер «Сервер устарел» в админке. Таблица донастраивается сама.
- **[сервер]** Столбцы «Заявок» ищутся по заголовкам; публикация не блокирует приём заявок.
- Цифры «О кондитерской» помещаются при любой ширине и длине.

## 1.0.0 — 2 ноября 2026
- Витрина, форма с календарём, Google-таблица + Apps Script, Telegram, админка с публикацией в GitHub.
